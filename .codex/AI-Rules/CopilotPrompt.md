# GitHub Copilot 提示詞規則

- 使用者要求「提供提示詞」時，代表將功能實作交由 GitHub Copilot 執行。
- 提示詞必須包含完整、清晰、可直接執行且限於目前專案的資訊，包括目標、相關檔案或 symbol、限制、驗收條件與測試要求。
- 不得假設 GitHub Copilot 能存取其他 Repository、外部工作區、先前對話或未提供的內容。
- 每次都根據任務的複雜度、風險、影響範圍、所需推理能力與額度成本，重新評估當下可用模型，並建議能可靠完成任務且額度使用合理的最低充分能力。日常實作與測試優先選擇成本合宜的模型；當跨模組推理、重大架構決策、疑難診斷或其他高風險需求需要更高能力時，再選擇高能力模型。模型建議應簡要說明與任務需求相符的選擇依據，高能力模型的建議應指出它能處理的具體挑戰。
- 若實作涉及測試或 Database，將對應規則中必要且可執行的要求寫入提示詞，不能只引用 Codex 本機路徑。
